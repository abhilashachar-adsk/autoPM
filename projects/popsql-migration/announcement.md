# PopSQL → ADP Studio Migration Announcement

## Slack Announcement

**Post to:** `#ad-query-support`, `#pset-ad-infra-support`, `#adp-community`

---

:rocket: **ADP Studio is your new query home — PopSQL migration is happening!**

Hi team,

We're excited to share that **ADP Studio** ([data.autodesk.com/query-experience](https://data.autodesk.com/query-experience)) is now the recommended query interface for all Data Lake and Snowflake querying. As part of this transition, **PopSQL will be retired on September 1, 2026**.

### What you need to know

**:calendar: April 17, 2026 — Cut-off date for auto-migration**
The platform team is building an automated migration that will transfer your PopSQL content — queries, folders, dashboards, notebooks, variables, and permissions — into ADP Studio. The **final PopSQL snapshot** will be taken on **April 17**. Any changes made in PopSQL after this date will **not** be part of the automated migration.

**:sparkles: Why ADP Studio?**
ADP Studio brings capabilities that PopSQL and DBeaver can't match:
- **AI Query Assistant** — generate SQL from plain English, auto-fix errors, get query explanations
- **No licensing limits** — open to all Autodesk users (PopSQL was capped at 170 seats)
- **No install needed** — fully web-based with SSO
- **Advanced templating** — Jinja2 with conditionals, loops, and custom functions
- **Integrated data catalog** — browse schemas, search tables with AI-powered semantic search
- **Enterprise security** — encrypted, audited, role-based access

**:clipboard: What to do before April 17**
1. **Clean up** your PopSQL queries — delete what you don't need, name your untitled drafts, organize into folders
2. **Try ADP Studio** — log in at [data.autodesk.com/query-experience](https://data.autodesk.com/query-experience) and run a few queries
3. **Report gaps** — if something in PopSQL is critical to your workflow and you don't see it in ADP Studio, tell us in [#ad-query-support](https://autodesk.enterprise.slack.com/archives/C094NSNAW07)

**:information_source: What about DBeaver?**
DBeaver is no longer a supported query tool. While it will continue to work as a standalone desktop app, all documentation, onboarding, and support will now point to ADP Studio. ADP Studio is simpler (SSO, no manual credentials), more powerful (AI assistant, data catalog), and built for collaboration.

**:page_facing_up: Full details**
- Migration guide: [data.autodesk.com/data-lake/query-interfaces](https://data.autodesk.com/data-lake/query-interfaces)
- Feature tracker & known gaps: [ADP Studio - Feature & Feedback Tracker](https://autodesk.atlassian.net/wiki/spaces/CPDDPS/pages/745193148)
- ADP Studio user guide: [ADP Studio - User Guide](https://autodesk.atlassian.net/wiki/spaces/CPDDPS/pages/333930171)

**:speech_balloon: Questions?**
Drop them in [#ad-query-support](https://autodesk.enterprise.slack.com/archives/C094NSNAW07) — we're here to help make this transition smooth.

Hi [Name],

We're writing to let you know about an important change to how you query data at Autodesk.

**PopSQL is being retired on September 1, 2026**, and **ADP Studio** is its replacement. ADP Studio is a web-based query platform built into the Data Portal that offers everything PopSQL does — and more, including an AI Query Assistant, unlimited access (no licensing caps), and integrated data catalog.

### Your action needed: April 17, 2026 cut-off

The platform team will automatically migrate your PopSQL content (queries, folders, dashboards, notebooks, variables, and permissions) into ADP Studio. The **final snapshot** of PopSQL will be taken on **April 17, 2026**.

**Any changes you make in PopSQL after April 17 will NOT be included in the automated migration.**

### What to do now

1. **Log in to ADP Studio** at [data.autodesk.com/query-experience](https://data.autodesk.com/query-experience) — it uses your Autodesk SSO credentials, no setup needed
2. **Clean up your PopSQL content** before April 17 — delete unused queries, name untitled drafts, organize folders
3. **Start using ADP Studio for new work** — anything you create in ADP Studio stays there; no migration needed

### What's better in ADP Studio

| Feature | PopSQL | ADP Studio |
|---|---|---|
| AI Query Assistant (text-to-SQL, auto-fix, explain) | Not available | Available now |
| Licensing | 170 seats | Unlimited |
| Installation | Desktop app or web | Web only — no install |
| Templating | Basic variables | Jinja2 (conditionals, loops, functions) |
| Data Catalog | Not available | Integrated with AI search |
| Authentication | SSO | SSO (same — no change) |

### Timeline

| Date | What happens |
|---|---|
| **Now – April 17** | Clean up PopSQL; start using ADP Studio for new work |
| **April 17** | Final PopSQL snapshot taken |
| **April 17 – May 15** | Platform team runs automated migration |
| **May 15 – June 1** | You verify your migrated content in ADP Studio |
| **September 1** | PopSQL access terminated |
