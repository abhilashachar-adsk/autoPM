# PSET / AD FY27 Planning Process

*Reference card for the strategic planning and realization cycle. Consult during weekly reviews and quarterly planning.*

---

## The Hierarchy

```
AD Strategic Intent (SI) — 3-year corporate vision
  └── Strategic Realization (SR) — 12-18 month priorities
       └── Platform Outcomes (L1) — measurable outcomes owned by PSET
            └── Capability / Domain Outcomes (L2/L3) — aligned to Capability Map
                 └── Features & Key Results — with KPIs and quarterly commits
                      └── Projects — PRDs, migrations, builds
                           └── Next Actions / Tasks — weekly execution
```

For AD Platform Infrastructure, we operate at L2/L3:
- **Initiatives = OKRs** (Regionalization, Self Service, Faster Cheaper Better, Next Gen Experiences)
- **Outcomes realize OKRs** — committed quarterly, reiterated each quarter
- **Projects are children of initiatives** — execution vehicles with next actions

## Annual SR Planning Cycle (Aug–Jan)

| Phase | Timing | What Happens | Artifacts |
|-------|--------|-------------|-----------|
| Ideation | Aug | Platform Outcomes captured, industry requests identified, domain outcomes brainstormed | Platform Outcomes list (Airtable) |
| Consolidation | Sep | Features identified, stakeholders & dependencies mapped, alignment discussions | Capability Strategy Memo, Outcome Memo |
| Prioritizing | Oct | KRs defined, stack ranking by Reach/Impact/Confidence | Platform check-in #1 (60%), #2 (90%), deep-dive deck |
| Roadmaps | Nov | Engineering sizing, dependency mapping, product discovery | High-integrity FY27 commitments |
| Q1 + Continuous Planning | Dec–Jan | Q1 Stack Hands, capacity planning, quarterly commit, KPIs drafted | Quarterly commit, KPI drafts |
| Detailed Planning | Dec–Feb | Business/Program Groups define FY scope, Initiative Briefs created | PDMS Global Backlog (Airtable) |

**Feb 2026 PSET/PDMS Planning Summit** — keystone event where FY27 roadmaps were presented.

## Continuous Governance (In-Year)

| Process | Cadence | Your Role |
|---------|---------|-----------|
| Quarterly SR Adjustment | Quarterly | Re-prioritize outcomes, update confidence in [[GTD/goals]], adjust backlog |
| Stakeholder Engagement | Continuous | Triage incoming requests via [PSET work intake](https://autodesk.atlassian.net/wiki/spaces/APMO/pages/467804697) (1-2 week SLA) |
| Platform Outcome Mgmt | Continuous | TPM-led lifecycle: Initiation → Planning → Executing → Monitoring → Closing |
| Monthly CTO Readout | Monthly | Top initiatives reviewed with L2 leaders |
| Capability Strategy Memos | Annual refresh | 3-year living docs grounded in [Capability Map](https://one.autodesk.com/apps/capability-map/) |
| PSET RFCs/ADRs | As needed | Architectural decisions impacting more than one org |
